§01 — 훈련 영역

4개의 인지 영역,
매일 균형 있게.

뇌의 능력은 단일 지표로 측정할 수 없습니다. 한국두뇌평가원은 인지 신경과학이 정의한 네 가지 핵심 영역을 매일 조금씩, 그러나 빠짐없이 훈련하도록 설계되었습니다.

§01.1 / MEMORY

기억력

MEMORY · 작업기억 · 회상

숫자, 단어, 위치, 패턴을 짧은 시간 안에 기억하고 정확하게 재현하는 능력. 학습, 대화, 일상 업무의 기반이 되는 인지 자원입니다.

숫자 회상단어 매칭얼굴 기억순서 따라잡기

§01.2 / MATH

수리력

MATH · 계산 · 추론

숫자 관계를 빠르게 파악하고 계산·추정·비교하는 능력. 재무 판단, 시간 관리, 논리적 문제 해결에 직접적으로 영향을 미칩니다.

§01.3 / COGNITION

인지력

COGNITION · 공간 · 추론

공간을 회전·변환하며 관계를 파악하고, 복잡한 정보 사이의 규칙을 발견하는 능력. 창의적 문제 해결과 새로운 상황 적응의 기반입니다.

도형 회전패턴 완성미로 탈출규칙 발견

§01.4 / FOCUS

집중력

FOCUS · 주의 · 반응

주의를 지속하고, 불필요한 자극을 억제하며, 필요한 순간 정확히 반응하는 능력. 실수 줄이기, 몰입, 안전한 판단의 핵심 요소입니다.
