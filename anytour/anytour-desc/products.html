1Header UI (공통)
설명 메인화면과 동일한 공통 헤더. 상세는 SB · 메인화면 ① 참조. "여행상품" 메뉴가 is-current로 강조된다.
2페이지 배너 UI
설명 여행상품 목록 페이지 배너. "네 갈래 여정" 카피와 패키지 여행 이미지로 페이지 성격을 안내한다.
구성요소 eyebrow(TRAVEL CATALOG·2026), 헤드라인, 서브카피 — 텍스트 가운데 정렬
3탭 필터 UI (#productTabs)
설명 상품을 카테고리별로 필터링하는 탭. URL 해시(#package 등)와 동기화되어 다른 페이지에서 특정 탭으로 직접 진입 가능하다.
구성요소 섹션 타이틀("원하는 여정을 선택하세요"), 탭 버튼 5개(전체보기/패키지/골프·테마/항공·호텔/단체·효도여행)
인터랙션
  • 탭 클릭 → 해당 카테고리 상품만 필터링해 하단 그리드 재렌더링, active 스타일 갱신, URL 해시 갱신
  • 최초 진입 시 URL 해시가 있으면 해당 탭 자동 활성화
4상품 리스트 그리드 (#productGrid)
설명 선택된 탭의 상품 개수와 정렬 토글을 상단에 노출하고, 상품을 카드형 그리드로 10개 단위 페이지네이션과 함께 제공한다. 인바운드 페이지(SB · 인바운드 ④)와 동일한 정렬 토글 패턴을 재사용한다.
구성요소 총 상품 수 카운트(#productGridCount), 정렬 토글(#productGridSortToggle — 인기순 기본 활성 / 최신순), 상품 카드(썸네일/지역/카테고리 태그/제목/평점/가격/해시태그), 페이지네이션(이전·숫자·다음), 하단 예시 데이터 고지문
인터랙션
  • 탭 전환 시 해당 탭의 상품 수로 카운트 갱신, 정렬 기준은 유지된 채 재정렬
  • 정렬 토글 클릭 → 인기순(판매량순) / 최신순으로 그리드 재정렬, 페이지 1로 리셋
  • 카드 클릭 → 카테고리에 따라 product-detail.html 또는 inbound-detail.html 이동
  • 페이지네이션 클릭 → 해당 페이지로 그리드 재렌더링, 그리드 상단으로 스무스 스크롤
5맞춤 상담 CTA 배너
설명 원하는 상품이 없는 사용자를 상담 문의로 유도하는 배너(.cta-band).
구성요소 안내 문구, "맞춤 상담 요청하기" 버튼
인터랙션 버튼 클릭 → contact.html 이동
6Footer UI (공통)
설명 메인화면과 동일한 공통 푸터. 상세는 SB · 메인화면 ⑥ 참조.

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/user/products.html)을 iframe으로 축소(50%) 표시한 라이브 미리보기이며 "전체보기" 탭 기준입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 헤더/푸터 include가 정상 렌더링됩니다.
