3리뷰 등록·필터·정렬
설명 리뷰 개수 옆에 "리뷰 등록" 버튼이 추가되었고, 그 아래에 리뷰 검색·종류·여행종류·별점 필터와 정렬 컨트롤이 이어진다.
구성요소 "리뷰 등록" 버튼, 검색 아이콘(확장형 입력창), 리뷰 종류(전체/포토) 셀렉트, 여행 종류 셀렉트, 별점 셀렉트(전체 별점/5점~1점), 정렬 셀렉트(최신순/평점높은순), 리뷰 작성/수정 모달(dialog)
인터랙션
  • "리뷰 등록" 클릭 → 리뷰 작성 모달 오픈(여행 종류·별점·작성자 이름·비밀번호·제목·내용·사진 첨부(최대 4장)). 비회원도 작성 가능
  • 모달에서 "리뷰 등록" 제출 → 등록 완료 안내 후 모달 닫힘(데모: 목록에는 실제 반영되지 않음)
  • 검색 아이콘 클릭 → 검색 입력창 펼침
  • 각 필터·정렬 변경 시 조건에 맞게 필터링/정렬하여 4번 영역을 재렌더링, 1페이지로 리셋
4리뷰 목록
설명 필터링된 리뷰를 포토 카드 그리드로 노출하고 페이지네이션으로 넘겨본다. 카드에는 상품명 대신 여행 종류만 표기한다.
구성요소 리뷰 포토 카드(#reviewGrid, 사진·별점·제목·날짜·여행종류 태그, 24개/페이지), 이전/다음 페이지 버튼 + 페이지 정보, 하단 예시 데이터 고지문, 상세 모달(dialog)
인터랙션
  • 리뷰 카드 클릭 → 상세 모달 오픈, 사진·별점·제목·날짜·여행 종류·"수정" 버튼 표시
  • 상세 모달의 "수정" 클릭 → 비밀번호 입력 확인 후(데모: 값 입력 시 통과) 리뷰 작성 모달이 수정 모드로 재사용되어 열림(여행 종류·별점·제목이 기존 값으로 채워짐), 제출 시 "리뷰 수정" 완료 안내
  • 모달 닫기(✕) 클릭 또는 배경 클릭 → 모달 닫힘
  • 이전/다음 버튼 클릭 → 페이지 전환, 버튼은 첫/마지막 페이지에서 비활성화
