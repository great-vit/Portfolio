1Header (공통)
설명 관리자 공통 헤더. 상세는 SB · 관리자 홈 ① 참조.
2내비게이션(상단 메뉴 + 사이드바)
설명 상단 메뉴에서 "상품관리" 탭이 활성화되고, 좌측 사이드바에 하위 메뉴가 노출된다.
구성요소 상단 메뉴 4탭(상품관리 활성), 사이드바 타이틀 "상품관리", 하위 메뉴 "상품 목록"(활성)
3검색·필터
설명 브레드크럼과 상품 목록 카드 헤더, 조건검색 폼을 포함하는 영역. "등록하기"는 더 이상 모달을 열지 않고 별도 페이지(상품 등록/수정)로 이동한다.
구성요소 브레드크럼(HOME > 상품관리), 카드 헤더("상품 목록" + "등록하기" 버튼), 조건검색 입력창(상품명·지역), 카테고리 셀렉트(전체/반려동물 동반여행/인바운드/패키지/골프·테마/항공·호텔/단체·효도여행), 등록기간 필터(시작일~종료일 날짜 선택), 초기화·검색 버튼
인터랙션
  • "등록하기" 클릭 → SB · 상품 등록/수정 페이지로 이동(등록 모드)
  • 검색어·카테고리·등록기간 조건으로 Enter 또는 "검색" 클릭 시 4번 목록 테이블 필터링
  • "초기화" 클릭 → 검색어·카테고리·등록기간 조건 초기화 후 전체 목록 재노출
4목록 테이블
설명 등록된 상품을 최신순으로 나열하는 테이블이며, 하단에 10건 단위 페이지네이션이 추가되었다.
구성요소 검색결과 건수, 전체선택 체크박스, 번호·카테고리·상품명·지역·가격·등록일·관리(수정/삭제) 컬럼, 페이지네이션(페이지당 10건), 하단 "선택삭제" 버튼
인터랙션
  • 전체선택 체크박스 클릭 → 현재 페이지에 노출된 행 체크박스 토글
  • 행의 "수정" 클릭 → SB · 상품 등록/수정 페이지로 이동(?id= 파라미터로 수정 모드 진입, 기존 값이 채워진 상태로 표시)
  • 행의 "삭제" 클릭 → 확인 후 해당 상품 1건 삭제
  • "선택삭제" 클릭 → 체크된 상품 일괄 삭제(선택 항목 없으면 안내)
  • 페이지네이션 번호/이전/다음 클릭 → 해당 페이지로 목록 갱신

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/products.html)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 등록/수정한 상품은 브라우저 세션 동안만(sessionStorage) 목록에 반영되며, 탭을 닫으면 초기 시드 데이터로 돌아갑니다. 실제 서비스에서는 사용자 화면(반려동물 동반여행/여행상품/인바운드)의 상품 데이터와 연동됩니다.
