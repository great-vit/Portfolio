4반려동반 추천 여행(RECOMMENDED)
설명 반려동물 카테고리 상품 개수·정렬 토글과 함께 카드형으로 노출하는 섹션(최대 8개). 여행상품(SB · 여행상품 ④), 인바운드(SB · 인바운드 ④)와 동일한 정렬 토글 패턴을 재사용한다.
구성요소 섹션 타이틀, 총 상품 수 카운트(#petProductGridCount), 정렬 토글(#petProductGridSortToggle — 인기순 기본 활성 / 최신순), 상품 카드 그리드(#petProductGrid, data-limit="8")
인터랙션
  • 페이지 로드 시 인기순(판매량순) 기준 상위 8개를 카드로 렌더링, 카운트는 전체 반려동물 상품 수로 표시
  • 정렬 토글 클릭 → 인기순 / 최신순 기준으로 재정렬 후 상위 8개 재렌더링
  • 카드 클릭 → pet-detail.html 이동
