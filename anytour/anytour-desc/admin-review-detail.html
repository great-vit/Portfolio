1배경(목록 화면)
설명 모달 뒤로 어둡게 처리된 배경은 리뷰 목록 화면이다. 목록 상세는 SB · 리뷰 관리 참조.
2리뷰 상세 모달
설명 SB · 리뷰 관리 목록에서 행의 "상세보기" 클릭 시 뜨는 모달. 사용자 화면(여행후기)에서 등록된 리뷰의 전체 내용을 확인하고, 관리자가 필요 시 평점·여행종류·제목·내용을 직접 수정할 수 있다. 기본은 조회 모드(모든 필드 비활성)로 열리며, "수정" 버튼을 눌러야 편집 모드로 전환된다.
구성요소 모달 타이틀("리뷰 상세"), 평점 셀렉트(★1~5, 조회 모드 시 비활성), 여행종류 셀렉트(조회 모드 시 비활성), 제목 입력창(조회 모드 시 읽기전용), 내용 textarea(조회 모드 시 읽기전용), 등록일 입력창(항상 읽기전용 — 수정 불가), 첨부 사진, 하단 "닫기"·"수정"·"저장" 버튼("저장"은 편집 모드에서만 노출)
인터랙션
  • 모달 오픈 시 조회 모드: "닫기"·"수정" 버튼만 노출, 나머지 필드는 모두 비활성/읽기전용
  • "수정" 클릭 → 평점·여행종류·제목·내용이 편집 가능 상태로 전환, "수정" 버튼은 숨겨지고 "저장" 버튼이 노출
  • "저장" 클릭 → 제목·내용 필수값 검증 후 저장, 조회 모드로 복귀하고 SB · 리뷰 관리 목록도 최신 내용으로 갱신
  • "닫기" 클릭 또는 배경 클릭 → 모달 닫힘, SB · 리뷰 관리 목록으로 복귀
  • 리뷰 삭제는 이 모달이 아니라 목록의 체크박스 + "선택삭제"로 처리한다

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/reviews.html)에 ?modal=detail을 붙여 목록 첫 번째 항목의 상세 모달이 자동으로 열린 상태를 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 데이터는 데모 시드값(브라우저 메모리)이며 새로고침하면 초기 상태로 돌아갑니다.
