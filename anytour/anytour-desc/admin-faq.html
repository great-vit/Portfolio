설명 관리자 공통 헤더. 상세는 SB · 관리자 홈 ① 참조.
2내비게이션(상단 메뉴 + 사이드바)
설명 상단 메뉴에서 "사이트관리" 탭이 활성화되고, 좌측 사이드바에 공지사항 관리·FAQ 관리·리뷰 관리 하위 메뉴가 노출된다.
구성요소 상단 메뉴 4탭(사이트관리 활성), 사이드바 타이틀 "사이트관리", 하위 메뉴 "공지사항 관리"·"FAQ 관리"(활성)·"리뷰 관리"
인터랙션 사이드바 "공지사항 관리"/"리뷰 관리" 클릭 → SB · 공지사항 관리 / SB · 리뷰 관리 이동
3검색·필터
설명 브레드크럼과 FAQ 카드 헤더, 조건검색 폼을 포함하는 영역.
구성요소 브레드크럼(HOME > 사이트관리 > FAQ 관리), 카드 헤더("FAQ" + "등록하기" 버튼), 조건검색 입력창(질문·답변), 노출여부 셀렉트(전체/노출/숨김), 초기화·검색 버튼
인터랙션
  • "등록하기" 클릭 → FAQ 등록 모달 오픈(질문·답변·정렬순서·노출여부 입력)
  • 검색어 입력 후 Enter 또는 "검색" 클릭 → 4번 목록 테이블 필터링
  • "초기화" 클릭 → 검색 조건 초기화 후 전체 목록 재노출
4목록 테이블
설명 등록된 FAQ를 정렬순서 기준으로 나열하는 테이블.
구성요소 검색결과 건수, 전체선택 체크박스, 번호·정렬순서·질문·노출여부(노출/숨김 배지)·등록일·관리(수정/삭제) 컬럼, 하단 "선택삭제" 버튼
인터랙션
  • 행의 "수정" 클릭 → 등록 모달에 기존 값이 채워진 상태로 오픈, 저장 시 해당 행 갱신
  • 행의 "삭제" 클릭 → 확인 후 해당 FAQ 1건 삭제
  • "선택삭제" 클릭 → 체크된 FAQ 일괄 삭제(선택 항목 없으면 안내)

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/faq.html)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 데이터는 데모 시드값(브라우저 메모리)이며 새로고침하면 초기 상태로 돌아갑니다. 실제 서비스에서는 사용자 화면(고객센터 > FAQ) 데이터와 연동됩니다.
