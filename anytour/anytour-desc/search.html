1Header UI (공통)
설명 메인화면과 동일한 공통 헤더. 상세는 SB · 메인화면 ① 참조.
인터랙션 검색창에 값이 남아있는 상태로 진입하며, 재검색 시 동일하게 이 화면(search.html)으로 다시 이동한다.
2검색결과 타이틀 영역
설명 현재 검색어와 결과 건수를 안내하는 영역.
구성요소
  • 타이틀: "“{검색어}” 검색결과"(검색어 없을 시 "검색결과"만 표시)
  • 카운트: "총 N개"
인터랙션 URL의 쿼리 파라미터(?q=)를 읽어 페이지 로드 시 1회 텍스트 반영, 별도 사용자 인터랙션 없음.
3검색 결과 리스트
설명 검색어와 매칭된 상품을 products.html과 동일한 카드 UI로 노출한다. 결과가 없으면 카드 대신 안내 문구를 노출한다.
구성요소
  • 상품 카드(썸네일/지역/제목/평점/가격/해시태그) — PC 기준 한 줄 4개, 페이지당 12개
  • 결과 없음 안내 문구(카드 영역 대신 노출)
인터랙션
  • 카드 클릭 → 카테고리에 따라 product-detail.html/pet-detail.html/inbound-detail.html 이동
  • 검색 결과 0건이면 카드 영역이 비고 하단 안내 문구만 노출
4페이지네이션
설명 검색 결과가 13개 이상일 때 페이지 단위(12개/페이지)로 넘겨보는 컨트롤.
구성요소 이전 버튼, 페이지 번호 버튼(전체 페이지 수만큼), 다음 버튼 — products.html/reviews.html과 동일한 페이지네이션 UI 재사용
인터랙션
  • 번호/이전/다음 클릭 → 해당 페이지 12개로 그리드 재렌더링, active 표시 갱신
  • 페이지 전환 시 결과 리스트 상단으로 스무스 스크롤
  • 결과가 12개 이하이면 페이지네이션 영역 비노출
5Footer UI (공통)
설명 메인화면과 동일한 공통 푸터. 상세는 SB · 메인화면 ⑥ 참조.

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/user/search.html?q=투어)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 헤더/푸터 include가 정상 렌더링됩니다. 데이터 연동 항목은 개발 단계에서 정하는 것으로 하고 이 문서에는 생략했습니다.
