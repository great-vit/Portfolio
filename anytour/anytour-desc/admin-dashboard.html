1Header (공통)
설명 모든 관리자 화면에 공통으로 노출되는 상단 바.
구성요소 "ADMINISTRATOR" 로고, 운영자 아바타·이름, "관리자" 권한 배지, HOMEPAGE 링크, LOG-OUT 링크
인터랙션
  • 로고 클릭 → admin/index.html(관리자 홈) 이동
  • HOMEPAGE 클릭 → 사용자 홈페이지(/user/main.html) 새 탭으로 이동
  • LOG-OUT 클릭 → admin/login.html 이동(데모 목적, 세션 처리 미연동)
2상단 메뉴(공통)
설명 관리자 기능을 4개 그룹으로 나눈 최상위 탭 메뉴. 관리자 홈에서는 활성 탭이 없다. 관리자 계정이 1개(고정)라는 전제로 계정관리를 가장 마지막 탭으로 배치했다.
구성요소 상품관리 / 사이트관리 / 문의관리 / 계정관리 4개 탭
인터랙션 탭 클릭 → 해당 그룹의 첫 화면으로 이동(상품관리→상품 목록, 사이트관리→공지사항 관리, 문의관리→문의·예약 관리, 계정관리→관리자 정보 수정)
3통계 카드
설명 주요 데이터 현황을 요약해 보여주는 카드 5개.
구성요소 전체 상품 수, 공지사항 수, FAQ 수, 등록된 리뷰 수, 대기중 문의 수(각 카드는 클릭 가능)
인터랙션 카드 클릭 → 해당 관리 화면으로 이동(등록된 리뷰 카드 → SB · 리뷰 관리)
4빠른 메뉴
설명 자주 쓰는 등록·확인 기능으로 바로 이동하는 바로가기 버튼 모음.
구성요소 상품 등록, 공지사항 등록, FAQ 등록, 문의·예약 확인, 리뷰 확인, 관리자 정보 수정 버튼
인터랙션 버튼 클릭 → 해당 관리 화면으로 이동("리뷰 확인" → SB · 리뷰 관리, "관리자 정보 수정" → SB · 계정관리)

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/index.html)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 통계 수치는 데모 데이터(seed-data.js) 기준이며, 실제 연동 시 서버 집계값으로 대체됩니다.
