1Header UI (공통)
설명 전 페이지 상단 고정(sticky) 공통 영역. 로고·검색·GNB를 제공하며 모든 페이지에서 동일하게 노출된다.
구성요소
  • 로고(A애니투어), 검색창(여행지·상품명)
  • GNB 7개: 회사소개/여행상품/반려동물 동반여행/인바운드/여행후기/고객센터/문의·예약
  • 모바일 햄버거 버튼, 검색 아이콘
인터랙션
  • 로고 클릭 → main.html 이동
  • 메뉴 클릭 → 해당 페이지 이동, 현재 메뉴는 밑줄 강조
  • 모바일: 햄버거 클릭 시 GNB 슬라이드 오픈/클로즈
  • 검색창: 키워드 입력 후 Enter 또는 검색 아이콘 클릭 → search.html?q=검색어로 이동(통합검색 결과 화면)
  • 검색어 미입력 상태로 제출 시 동작 없음(placeholder 유지)
  • 모바일은 mobile-search 영역의 검색창이 동일 폼으로 동일하게 동작
2Hero Slider UI
설명 메인 최상단 풀와이드 이미지 슬라이더. 브랜드 핵심 메시지(반려동물 동반여행 등)를 순환 노출한다.
구성요소
  • 슬라이드 3장
  • 이전/다음 버튼, 현재 슬라이드 카운터(1/3)
인터랙션
  • 6초 간격 자동 재생
  • 이전/다음 버튼 클릭 시 슬라이드 전환 + 자동재생 타이머 리셋
3타임특가 섹션
설명 기간 한정 할인 상품 4개를 카드형으로 노출, 상단 필터 칩으로 카드를 실제 필터링한다.
구성요소
  • 필터 칩 4개(#소형견동반 기본 활성 · #대형견동반 · #국내펜션 · #해외동반), 상품 카드 4개(썸네일/태그/상품명/정가·할인가)
인터랙션
  • 페이지 로드 시에도 기본 활성 칩(#소형견동반) 기준으로 카드가 필터링된 상태로 시작
  • 카드 클릭 → product-detail.html 이동
4월간 Best 랭킹 섹션
설명 인기 Top3 상품을 순위 배지와 대형 이미지 카드로 노출.
구성요소
  • 순위 카드 3개(1~3위 배지, 배경이미지, 제목, 해시태그)
인터랙션 카드 클릭 → inbound-detail.html 이동
5이미지 갤러리 섹션
설명 여행지 사진 중심의 감성 4분할 갤러리. 다크 배경으로 앞 섹션과 톤을 구분한다.
구성요소 갤러리 카드 4개(배경 이미지 + 하단 오버레이 상품명·가격)
인터랙션 카드 클릭 → product-detail.html 이동
6Footer UI (공통)
설명 전 페이지 공통 하단 영역. SNS·사이트맵·회사정보·저작권을 제공한다.
구성요소
  • SNS 아이콘 4개, 로고 + 고객센터 전화
  • 여행상품/고객지원 링크 목록
  • 회사정보(대표/주소/전화/사업자등록번호), 저작권, 약관 링크 2개
인터랙션
  • 각 링크 클릭 → 해당 페이지 이동

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/user/main.html)을 iframe으로 축소(50%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 헤더/푸터 include가 정상 렌더링됩니다. ※ 모바일 등 좁은 화면에서 한글 텍스트가 단어 중간에서 줄바꿈되던 문제를 body { word-break: keep-all; }로 수정했다(사이트 전체 공통 적용, 특정 화면 전용 항목은 아니라 별도 마커는 두지 않음).
