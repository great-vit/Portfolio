1Header (공통)
설명 관리자 공통 헤더. 상세는 SB · 관리자 홈 ① 참조.
2내비게이션(상단 메뉴 + 사이드바 + 브레드크럼)
설명 상단 메뉴에서 "상품관리" 탭이 활성화되고, 브레드크럼 마지막 항목이 등록/수정 모드에 따라 "상품 등록" 또는 "상품 수정"으로 표시된다.
구성요소 상단 메뉴 4탭(상품관리 활성), 사이드바 하위 메뉴 "상품 목록", 브레드크럼(HOME > 상품관리 > 상품 등록/수정)
3기본 정보
설명 SB · 상품관리의 목록에 그대로 노출되는 기본 항목이며, 기존 필드 구성은 그대로 유지했다.
구성요소 카테고리 셀렉트, 상품명 입력창, 지역·가격(원) 입력창, 해시태그 입력창(쉼표 구분)
4핵심 방문지
설명 사용자 화면 상품 상세의 "핵심 방문지" 섹션에 들어갈 항목을 관리자가 직접 입력하는 반복형 폼. 이미지와 텍스트(설명·장소명)만 입력하면 되도록 구성했다.
구성요소 방문지 행(사진 첨부 버튼 + 설명 입력창 + 장소명 입력창 + 삭제 버튼) N개, "+ 방문지 추가" 버튼
인터랙션
  • "+ 방문지 추가" 클릭 → 방문지 입력 행 1개 추가
  • 행의 "삭제" 클릭 → 해당 방문지 행 제거
5상세설명·사진첨부
설명 상품 상세 페이지 본문에 들어갈 설명 텍스트와 참고 사진을 입력하는 영역.
구성요소 상세설명 텍스트영역, 사진 첨부 버튼(다중 선택)
6일정 안내
설명 사용자 화면 상품 상세의 "일정 안내"(1일차/2일차… 탭) 데이터를 입력하는 반복형 폼. 일차 단위로 소제목과 항목 목록만 입력하면 되도록 구성했다.
구성요소 일차 블록(N일차 라벨 + 일차 삭제 버튼 + 소제목 입력창 + 일정 항목 입력창 N개 + "+ 항목 추가" 버튼) N개, "+ 일차 추가" 버튼, 하단 "취소"·"저장(수정하기)" 버튼
인터랙션
  • "+ 일차 추가" 클릭 → 새 일차 블록 추가(번호 자동 재계산)
  • "일차 삭제" 클릭 → 해당 일차 블록 제거(번호 자동 재계산)
  • "+ 항목 추가"/항목 행의 "삭제" 클릭 → 해당 일차 내 일정 항목 추가/제거
  • "저장"(등록) 또는 "수정하기"(수정) 클릭 → SB · 상품관리 목록으로 이동, 해당 세션 동안 목록에 반영
  • "취소" 클릭 → 입력 내용 저장 없이 SB · 상품관리 목록으로 이동

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/product-form.html)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 등록 모드 기준 화면이며, 목록에서 "수정" 클릭 시 같은 화면에 기존 값이 채워진 상태로 진입합니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 사진 첨부는 파일명만 저장하는 데모이며 실제 업로드·저장은 개발 단계에서 연동됩니다.
