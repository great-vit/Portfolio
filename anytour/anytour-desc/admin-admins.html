1Header (공통)
설명 관리자 공통 헤더. 상세는 SB · 관리자 홈 ① 참조.
2내비게이션(상단 메뉴 + 사이드바)
설명 상단 메뉴에서 "계정관리" 탭이 활성화되고, 좌측 사이드바에 하위 메뉴가 노출된다. 계정관리는 관리자가 1명(고정 계정)이라는 전제로 상단 메뉴의 가장 마지막 탭으로 배치했다.
구성요소 상단 메뉴 4탭(상품관리/사이트관리/문의관리/계정관리 순, 계정관리 활성), 사이드바 타이틀 "계정관리", 하위 메뉴 "관리자 정보 수정"(활성)
3관리자 정보 수정 폼
설명 관리자 계정이 1개(고정)라는 전제로, 기존의 계정 목록·검색·등록/수정 모달 방식을 걷어내고 로그인한 관리자 본인의 정보를 바로 수정하는 단일 폼으로 구성했다. 목록·페이지네이션이 필요 없다. 아이디도 이름·연락처·이메일과 동일하게 이 폼에서 바로 수정할 수 있다.
구성요소 브레드크럼(HOME > 계정관리), 카드 헤더("관리자 정보 수정"), 아이디 입력창(필수, 수정 가능), 이름·연락처·이메일 입력창(필수), 비밀번호 입력창(선택, placeholder "변경 시에만 입력"), "수정하기" 버튼
인터랙션
  • 아이디·이름·연락처·이메일은 필수 입력이며, 비밀번호는 값을 입력한 경우에만 변경된다(비워두면 기존 비밀번호 유지)
  • "수정하기" 클릭 → 유효성 확인 후 저장, 완료 안내
  • 아이디를 다른 관리자 계정과 중복되는 값으로 변경 시도하면 "이미 사용 중인 아이디입니다" 오류를 안내하고 저장을 막는다

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/admins.html)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 데이터는 데모 시드값(브라우저 메모리)이며 새로고침하면 초기 상태로 돌아갑니다. 실제 비밀번호 암호화·인증 로직은 개발 단계에서 연동됩니다.
