1로고 / 타이틀
설명 중앙 정렬된 카드 형태 로그인 화면. 공통 헤더·푸터 없이 단독 화면으로 구성된다.
구성요소 "ADMINISTRATOR" 로고 텍스트, "애니투어 관리자 페이지" 서브카피
2로그인 폼
설명 아이디·비밀번호 입력 후 로그인하는 폼.
구성요소 아이디 입력, 비밀번호 입력, "로그인" 버튼, 오류 안내 배너(입력값 없을 때만 노출), 하단 데모 안내 문구
인터랙션
  • 아이디 또는 비밀번호가 비어 있으면 상단에 오류 배너 노출, 입력창은 초기화되지 않음
  • 아이디·비밀번호를 모두 입력 후 "로그인" 클릭 → admin/index.html(관리자 홈) 이동(데모 목적, 실제 인증 로직 미연동)

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/login.html)을 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 관리자 화면은 기능 중심 데모로, 실제 로그인·권한 처리 로직은 개발 단계에서 연동됩니다.
