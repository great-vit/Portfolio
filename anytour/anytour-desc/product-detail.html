2타이틀 바
설명 상품명과 출발 가능일, 공유하기 버튼을 상단에 고정 노출.
구성요소 상품명(h1), 출발 가능일 텍스트, "공유하기" 버튼
인터랙션 "공유하기" 버튼(#detailShare) 클릭 → 공유 실행(현재 프로토타입은 버튼만 존재, 실제 공유 로직은 Web Share API 또는 링크복사로 구현 필요)
3히어로(detail-hero)
설명 상품 대표 이미지 위에 카테고리·상품명·해시태그를 노출하는 배너.
구성요소 eyebrow(카테고리), 헤드라인(h2), 해시태그
4포함 내역(CHECK POINT)
설명 상품에 포함된 서비스 항목을 아이콘 카드 그리드로 요약.
구성요소 체크포인트 카드 6개(썸네일 + 타이틀 + 설명)
5방문지(DESTINATIONS)
설명 핵심 방문지를 사진과 캡션으로 소개.
구성요소 방문지 카드 6개(사진 + 캡션)
6일정 안내(ITINERARY)
설명 일자별 일정을 탭으로 전환해서 볼 수 있는 영역.
구성요소 일자 탭 버튼(1~4일차), 일자별 패널(제목 + 일정 리스트)
인터랙션 탭 클릭 → 해당 일자 패널만 active로 전환해 노출
7CTA 배너
설명 정확한 견적·출발일은 상담을 통해 안내한다는 CTA.
인터랙션 "상담 문의" 버튼 클릭 → contact.html 이동
8Footer UI (공통)
설명 메인화면과 동일한 공통 푸터. 상세는 SB · 메인화면 ⑥ 참조.
