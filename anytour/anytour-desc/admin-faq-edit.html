1배경(목록 화면)
설명 모달 뒤로 어둡게 처리된 배경은 FAQ 목록 화면이다. 목록 상세는 SB · FAQ 관리 참조.
2FAQ 수정 폼
설명 SB · FAQ 관리의 행에서 "수정" 클릭 시 뜨는 모달. SB · FAQ 등록과 동일한 폼에 기존 값이 채워진 상태로 열린다.
구성요소 모달 타이틀("FAQ 수정"), 질문·답변·정렬순서·노출여부 — 선택한 FAQ의 기존 값으로 채워짐, 하단 "취소"·"저장" 버튼
인터랙션
  • "저장" 클릭 → 유효성 확인 후 해당 FAQ 갱신, SB · FAQ 관리 목록으로 복귀
  • "취소" 클릭 또는 배경 클릭 → 변경 내용 저장 없이 모달 닫힘

※ 좌측 화면은 실제 프로토타입(04_storyboard/prototype/admin/faq.html)에 ?modal=edit를 붙여 목록 첫 번째 항목의 수정 모달이 자동으로 열린 상태를 iframe으로 축소(55%) 표시한 라이브 미리보기입니다. 프로토타입 수정 시 이 화면도 자동으로 최신 상태를 반영합니다. 로컬 서버(serve.ps1)로 열어야 정상 렌더링됩니다. 데이터는 데모 시드값(브라우저 메모리)이며 새로고침하면 초기 상태로 돌아갑니다.
